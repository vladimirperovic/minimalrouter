# Minimal Router dashboard preview

One-page Apple × Swiss interface prototype based on the project's `DESIGN.md`,
`PROJECT.md`, `ARCHITECTURE.md`, and `SECURITY.md`.

## Local preview

```sh
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Production build

```sh
pnpm build
```

The current values and controls are illustrative. The production interface will
receive state from the versioned Minimal Router REST API.
